# Лабораторна робота 5 - Ліниві обчислення

**Варіант 11:** Послідовність факторіалів.

## Завдання
Побудувати потік `0!, 1!, 2!, ...` без повторного перерахунку та отримати перші N значень.

## Структура проєкту
- `streams.py` — реалізація генераторів та утиліт (`take`, `drop`, `sliding_window`).
- `main.py` — демонстрація роботи коду.
- `tests/test_streams.py` — автоматизовані pytest-тести, включаючи перевірку "лінивості".

## Запуск та перевірка

1. Створіть віртуальне середовище та активуйте його:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   ```
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть тести:
   ```bash
   pytest
   ```
4. Запустіть демонстраційний скрипт:
   ```bash
   python main.py
   ```
